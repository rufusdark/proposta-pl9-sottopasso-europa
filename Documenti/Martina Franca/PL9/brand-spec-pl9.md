# Barocco Cosmico — Instagram brand spec

## Sei token colore (OKLch)

```css
:root {
  --bg:      oklch(18.5% 0.038 265);   /* #0a1628 navy */
  --surface: oklch(22% 0.04 265);       /* #0e1d33 slightly lighter navy */
  --fg:      oklch(92% 0.015 85);       /* warm white for body */
  --muted:   oklch(68% 0.04 85);        /* muted gold */
  --border:  oklch(35% 0.045 85);       /* dark gold border */
  --accent:  oklch(72% 0.12 85);        /* #d4a843 gold */
}
```

## Font stack
- **Display:** `'Playfair Display', Georgia, 'Times New Roman', serif`
- **Body:** `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif`

## Posture
- Navy deep-space background, gold accents
- Stars and elliptical flow lines (orbital theme)
- Elegant, cosmic-baroque feel ("Barocco Cosmico")
- One gold accent color, used sparingly for maximum impact
- Generous tracking on display type
- Clean, centered composition
