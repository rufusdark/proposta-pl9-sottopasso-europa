Il presente documento raccoglie in forma sistematica tutte le formule matematiche utilizzate nei documenti della proposta PL9 "Sottopasso Rotatoria Europa". Ogni formula è presentata con:

  • la notazione simbolica completa;

  • il risultato intermedio di ogni passaggio;
  • il risultato finale con verifica di congruità.

I dati provengono dal Quadro economico e analisi finanziaria (02_Quadro_Economico.html), dalla Relazione tecnico-illustrativa (01_Relazione_Tecnica.html) e dal Documento completo (COMPLETA.html).

La verifica indipendente è stata condotta con il supporto di Julis AI e con ricalcolo manuale di ogni passaggio.

5. Indicatori di redditività

5.1 Fattore di rendita (annuity factor) — 50 anni @ 3,5%

Fattore rendita = [ 1 − (1 + r)−n ] / r

dove:
r = 0,035 (tasso di attualizzazione 3,5%)
n = 50 (vita utile in anni)

Fattore rendita = [ 1 − (1,035)−50 ] / 0,035

Passaggio 1 — Calcolo del denominatore: (1,035)−50 = 0,1791

Passaggio 2 — Calcolo del numeratore: 1 − 0,1791 = 0,8209

Passaggio 3 — Divisione: 0,8209 / 0,035 = 23,4556

Fattore rendita = 23,4556 ✓ Verificato con ricalcolo indipendente

5.2 VAN — Valore Attuale Netto

VAN = −Costo_iniziale + Flusso_netto × Fattore_rendita

VAN = −1.242.000 + 264.522 × 23,4556

Passaggio 1: 264.522 × 23,4556 = €6.204.639

Passaggio 2: −1.242.000 + 6.204.639 = €4.962.639

VAN = €4.962.639 → arrotondato €4.963.000 ✓ Verificato

5.3 Rapporto B/C (Benefici/Costi)

B/C = PV_Benefici / (Investimento_iniziale + PV_Costi_gestione)

PV Benefici: PV(B) = 270.480 × 23,4556 = €6.344.275

PV Costi gestione: PV(Cop) = 5.958 × 23,4556 = €139.753

B/C = 6.344.275 / (1.242.000 + 139.753)
B/C = 6.344.275 / 1.381.753
B/C = 4,59 ✓ 4,59:1 — Verificato

5.4 Payback semplice

Payback semplice = Costo_iniziale / Flusso_netto_annuo

Payback semplice = 1.242.000 / 264.522
Payback semplice = 4,695 anni
Payback semplice = 4,70 anni (arrotondato) ✓ Verificato: 4,695 ≈ 4,70

5.5 Payback attualizzato

Il payback attualizzato è il tempo n tale che: Costo_iniziale = Flusso_netto × [1 − (1 + r)−n] / r

1.242.000 = 264.522 × [1 − 1,035−n] / 0,035

Passaggio 1 — Isolamento del fattore: [1 − 1,035−n] / 0,035 = 1.242.000 / 264.522 = 4,695

Passaggio 2: 1 − 1,035−n = 4,695 × 0,035 = 0,1643

Passaggio 3: 1,035−n = 1 − 0,1643 = 0,8357

Passaggio 4 — Logaritmi: −n × ln(1,035) = ln(0,8357)
−n × 0,03440 = −0,1795
n = 0,1795 / 0,03440
n = 5,22 anni ✓ Verificato

5.6 TIR — Tasso Interno di Rendimento

Il TIR è il tasso i che annulla il VAN: 0 = −1.242.000 + 264.522 × [1 − (1 + i)−50] / i

Per n=50 anni, il termine (1+i)−50 → 0 per i > 10%, quindi: 1.242.000 ≈ 264.522 / i
i ≈ 264.522 / 1.242.000
i ≈ 0,213 = 21,3%

Verifica: VAN(21,3%) = −1.242.000 + 264.522 / 0,213 × [1 − (1,213)−50]
= −1.242.000 + 1.241.887 × [1 − ≈0]
= −1.242.000 + 1.241.887 ≈ €0 ✓ TIR = 21,3% (VAN ≈ 0)
